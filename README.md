# 🧠 API de Correção de Texto com IA

Esta é uma API REST desenvolvida em **Node.js** que utiliza a Inteligência Artificial do Google (Gemini) para corrigir textos em português. 

## 🚀 Sobre o Projeto

O objetivo desta API é receber um texto com possíveis erros gramaticais ou de digitação via requisição `POST`, enviar para o modelo de IA do Google, e retornar **apenas** o texto corrigido.

## 🛠️ Tecnologias Utilizadas

- **Node.js**
- **Express.js**
- **Google Generative AI (Gemini)**
- **Dotenv**
- **CORS**
